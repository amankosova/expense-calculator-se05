# Expense Calculator

A small Python CLI utility for calculating expense totals, filtering expenses by category, and loading expense records from JSON files.

## Project Structure
- `calculator.py` — core calculation, filtering, summarization, and JSON loading logic
- `test_calculator.py` — automated unit tests (`pytest`)
- `requirements.txt` — Python test dependency (`pytest`)
- `AGENTS.md` — coding agent instructions and boundaries

## Setup
```bash
python -m pip install -r requirements.txt
